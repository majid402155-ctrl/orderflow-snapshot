# Kennedy SaaS Frontend — Roadmap Folder

This folder is the single place that records **what is done**, **what is next**, and
**what we are blocked on**. The short checkbox list lives in `/roadmap.md` at the project
root; the detail lives here. Everything is written against **backend v2.4**.

| File | What it holds |
|---|---|
| `00-overview.md` | The product, the five surfaces, the constraints, how the plan is organised |
| `01-done.md` | Everything completed so far, slice by slice, with the files touched |
| `02-next.md` | The slice being built now and the ones queued behind it |
| `03-blockers.md` | Questions only the backend/owner can answer |
| `04-contract.md` | The v2.4 backend contract we code against |
| `05-gap.md` | Screen-by-screen gap: built / partial / missing / wrong against v2.4 |

Rule: after every slice, update `01-done.md`, `02-next.md` and `05-gap.md` before writing
new code.
