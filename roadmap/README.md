# Kennedy SaaS Frontend — Roadmap Folder

This folder is the single place that records **what is done**, **what is next**, and
**what we are blocked on**. The short checkbox list lives in `/roadmap.md` at the
project root; the detail lives here.

| File | What it holds |
|---|---|
| `00-overview.md` | The product, the constraints, how the plan is organised |
| `01-done.md` | Everything completed so far, slice by slice, with the files touched |
| `02-next.md` | The slice being built now and the ones queued behind it |
| `03-blockers.md` | Questions only the backend/owner can answer |
| `04-contract.md` | The verified backend contract we code against |

Rule: after every slice, update `01-done.md` and `02-next.md` before writing new code.
